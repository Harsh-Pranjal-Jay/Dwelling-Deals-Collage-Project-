# Dwelling Deals - College Project

At Dwelling Deals, we specialize in helping you find your perfect home, investment property with confidence. Whether you're buying, selling, or renting, our platform connects you with the latest listings, expert insights, and dedicated agents who are ready to guide you through every step of the real estate journey.

## Project Structure

- `api/` - Backend API implementation
- `client/` - Frontend application
- `Input and Output Design/` - Project documentation and design files

3. Set up environment variables in `.env`
4. Run the development server using `npm start`
